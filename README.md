

Minimal LSPosed companion APK for the `FrameForce` module by bababoi. It contains the database whitelist UI and targeted Game Cube hooks for interpolation and super-resolution gates. It does not include thermal spoofing, frequency controls, or a daemon.

Choose either 90 → 72 → 144 or 120 → 60 → 120 in the profile selector. Apply stays disabled until root, the FrameForce module, LSPosed, a Meta Mount metamodule, and the Game Cube databases pass checks. Tap the requirement panel to refresh checks; confirm the LSPosed Game Cube scope before Apply unlocks. The selected profile is applied to the database and runtime fallback values. It updates Vivo Game Cube databases for listed games and installed third-party apps, then turns on the hook flag. The LSPosed entry scopes hooks to `com.vivo.gamecube`; enable that scope in LSPosed and restart Game Cube after applying. **Disable LSPosed hooks** turns off runtime hooks. **Revert to original settings** restores the baseline DB snapshot, disables hooks, and disables the overlay module for the next reboot. It does not generate interpolation or super-resolution if the OEM firmware does not support them.
